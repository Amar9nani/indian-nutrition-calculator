How it works

This calculator uses AI to estimate the nutritional value of Indian dishes by:

  1. Fetching a generic recipe for the dish
  2. Mapping ingredients to a nutrition database
  3. Converting quantities to standard measurements
  4. Calculating total nutrition values
  5. Standardizing to per-serving nutrition
