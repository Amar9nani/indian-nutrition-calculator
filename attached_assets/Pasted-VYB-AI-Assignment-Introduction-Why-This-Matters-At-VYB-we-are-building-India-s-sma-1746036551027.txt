# 📘 Introduction: Why This Matters

At VYB, we are building India's smartest health assistant. One key challenge we solve is:

> **"Given a home-cooked Indian dish name, estimate the nutritional value per standard serving."**

Indian cooking varies by household, so traditional databases fall short. Hence, we need AI systems that intelligently:
- Understand dishes
- Map ingredients accurately
- Calculate nutrition reliably

You will help us prototype a basic AI pipeline for this.

---

# ✨ Pre-requisites Provided

You will be given:Assignment Inputs
- A **sample Nutrition Database** (derived from IFCT-2017)
  - Contains nutrition info **per 100g** of common Indian ingredients
  - Includes: Calories, Protein, Carbs, Fat, Fiber
- A **standardized household measurement mapping for food item categories** (e.g., 1 katori = 200ml = ~180g for Wet Sabzi)



---

# 💪 Your Challenge: Problem Statement

Build a program that does the following:
Take a dish name as input (e.g., "Paneer Butter Masala")
Fetch a generic recipe (only the ingredient list; quantities can be in raw or approximate units).
Then, convert the ingredient quantities into the defined household measurements (e.g., katori, cup, glass, tsp) using a standard unit conversion step. 
Map ingredients to the Nutrition Database (handle synonyms / spelling variations smartly) 
Standardize quantities into grams using a household measurement table. You can also ask the LLM to generate estimated gram weights for each ingredient based on the standardized household measurements to improve accuracy. 
Calculate total nutrition using a sum-product of (quantity * nutrition per 100g)
 Identify food type by mapping the dish to one of the predefined categories (e.g., Wet Sabzi, Dry Sabzi, Dal, Non-Veg Curry) from the provided list. 
Extrapolate nutrition for a standard serving size (e.g., 1 katori of Wet Sabzi = ~180g)
Return nutrition per standard serving
⚡ Failure Handling (Important):
Please anticipate messy real-world data. Your program should handle common failures gracefully, such as:
Missing or invalid recipe data
Ingredient not found in Nutrition Database
Quantity conversion gaps
Outlier nutrition calculations (e.g., extremely high/low calories per 100g)
Failure to classify food type
It's okay to default, skip, or gently warn — but the program should not crash.
Smart fallback assumptions (with logging) will be appreciated.


---

# 🌍 Real-World Assumptions
- Recipes fetched are for 3–4 people unless specified.
- If full cooked weight is 800g and Wet Sabzi serving is 180g, scale nutrition proportionally.
- Ignore water loss during cooking for now.
- If no direct match found in database, handle gracefully.
